# Competitive Positioning — Comparison Content

Public-facing comparison talking points (for a future `/vs` page or sales-enablement one-pager — see `docs/marketing/sales-enablement.md`).

## AdGrid vs. traditional OOH advertising
| | Traditional OOH | AdGrid |
|---|---|---|
| Minimum spend | Often $1,000s | None |
| Sales process | Agency/rep required | Self-serve signup |
| Pricing | Negotiated, opaque | Real-time, transparent |
| Time to launch | Weeks | Minutes |

## AdGrid vs. "just boost a Facebook post"
| | Social ads | AdGrid |
|---|---|---|
| Presence | Scroll-past, feed-only | Physical, always-on, hard to ignore |
| Local relevance | Broad targeting | Literally in the neighborhood |
| Screen owner benefit | None | Screen owner earns revenue too |

## AdGrid vs. doing nothing (operator side)
An idle screen running a stock slideshow earns $0. AdGrid turns it into a revenue line with zero setup cost and no ongoing effort beyond approving creative.
