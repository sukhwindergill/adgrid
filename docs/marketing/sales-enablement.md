# Sales Enablement — AdGrid

AdGrid is self-serve, but early-stage operator recruitment and larger advertiser accounts (multi-location retail, property managers with multiple screens) benefit from a light sales-assist motion.

## One-pager (operator-facing)
- Headline: "Turn your screen into revenue — free to list."
- 3 bullets: no cost to list, you set the price, get paid automatically (weekly payout).
- Objection handling: "What if no one books it?" → house-ads fallback keeps screens active; "Is this a contract?" → no, cancel anytime.
- CTA: signup link with `ref`/UTM tracking (`attribution.md`).

## One-pager (advertiser-facing, for larger accounts)
- Headline: "Local out-of-home advertising, self-serve, no minimums."
- 3 bullets: real-time pricing, launch in minutes, screens in real local venues (not just billboards).
- Comparison table reused from `competitors.md`.

## Objection library (build out as real objections surface via `customer-research.md`)
| Objection | Response |
|---|---|
| "I don't have time to manage ads" | Self-serve setup takes minutes; creative approval is one click. |
| "How do I know this actually works?" | Real-time dashboard shows plays delivered per screen. |
| "What if my screen doesn't get booked?" | House ads fill unsold time automatically — screen is never dark. |
