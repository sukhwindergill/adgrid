# Video Marketing — AdGrid

## Fit assessment
Moderate fit — video is well-suited to demonstrating a *physical, visual* product (a screen playing an ad in a real venue), which is harder to convey in static copy/images alone.

## Recommended videos
1. **15-30s "how it works" explainer** — split-screen: operator side (list → approve → earn) and advertiser side (pick screen → set budget → launch), reinforcing the two-sided value prop from the hero copy.
2. **Real screen footage** — short clips of an actual ad playing on an actual screen in a gym/cafe (once available), used on the homepage near `OperatorsSection`/`AdvertisersSection` and in paid social (`ad-creative.md`).
3. **Operator testimonial** (once real operators exist) — 30-60s, "I didn't expect my screen to earn anything" framing, ties to `marketing-psychology.md` social proof gap.

## Placement
Homepage hero or immediately below it (autoplay muted, captioned) — current `Hero.jsx` uses a static image (`hero-gym.jpg`); a short looping video in the same slot would likely outperform a still image but is a larger asset-production and performance-budget decision, not made in this pass.

## Status
No video assets or video component exist in the repo yet — this is a recommendation for future production, not a code change.
